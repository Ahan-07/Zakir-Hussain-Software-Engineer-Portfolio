Technical depth

The typical architecture behind my full-stack projects, and the practices I try to hold myself to.

Client (Browser)
React Frontend
REST API
Node.js / Express
MongoDB / MySQL
  • Authentication & role-based authorization on every protected route
  • Server-side input validation, not just frontend checks
  • Parameterized queries to prevent SQL injection
  • Output encoding and sanitization to prevent XSS
  • Environment variables kept out of source control
